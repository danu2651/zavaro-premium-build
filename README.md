# ZAVARO Premium Frontend

Frontend-only luxury fashion ecommerce build using HTML5, CSS3 and Vanilla JavaScript.

## Files
- index.html
- style.css
- script.js
- assets/images/ 

## Existing asset paths
The JavaScript/HTML references the existing ZAVARO paths:
- assets/images/board_1_crops/
- assets/images/board_2_crops/
- assets/images/board_4_crops/

Do not rename those folders unless you also update the references.

## Features
Responsive editorial homepage, Mens/Womens/Kids worlds, collection views, category filtering, search, quick product view, wishlist, localStorage cart, checkout, order-number generation, responsive mobile navigation, and service pages.

Orders are currently stored in localStorage under `zavaro-orders`. The order object is structured for a later Node.js/Express/PostgreSQL API.
